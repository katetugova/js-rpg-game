# JavaScript RPG Game

Небольшая браузерная RPG-игра, разработанная на чистом JavaScript без использования фреймворков.

## Возможности

- Перемещение между игровыми локациями.
- Сражения с противниками.
- Система здоровья, силы и защиты персонажа.
- Получение опыта и повышение уровня.
- Инвентарь и использование предметов.
- Выпадение предметов после сражений.
- Журнал игровых событий.
- Состояние окончания игры.

## Технологии

- HTML5
- CSS3
- JavaScript

## Игровая механика

Игрок исследует несколько локаций с разным уровнем сложности: лес, руины и подземелье. Деревня служит безопасной зоной, где можно восстановить здоровье.

Во время исследования игрок может встретить противника и вступить в пошаговый бой. За победу начисляется опыт, а с противников могут выпадать предметы.

### Развитие персонажа

За получение новых уровней увеличиваются характеристики персонажа:

- максимальное здоровье;
- сила;
- защита.

### Предметы

В игре доступны лечебные зелья, оружие, щиты и свиток телепортации. Предметы можно получать после победы над противниками и использовать через инвентарь.
