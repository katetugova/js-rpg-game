# JavaScript RPG Game

Небольшая браузерная RPG-игра, разработанная на чистом JavaScript без использования фреймворков.

## Возможности

- Перемещение между игровыми локациями.
- Сражения с противниками.
- Система здоровья, силы и защиты персонажа.
- Получение опыта и повышение уровня.
- Инвентарь и использование предметов.
- Выпадение предметов после сражений.
- Журнал игровых событий.
- Состояние окончания игры.

## Технологии

- HTML5
- CSS3
- JavaScript
